# ClassOUT

**一款纯离线、无广告、不需要联网的鸿蒙（HarmonyOS / ArkTS）「课表 + 待办 + 计划」三合一 App。**

数据只存在你自己的手机里：不联网、不上传、不需要注册。第一次打开是**一张空课表**，
跟着下面「从零开始」四步走一遍，五分钟就能用起来。

> 🧭 **第一次上手？** 首次打开时会问你要不要走一遍**新手演练**（设置页里也随时能进）。
> 演练会开一个**沙箱**（里面有几门演示课和演示待办），你随便改、随便删；
> 退出时整个沙箱丢掉，你自己的课表一点都不会动。

## 1. 装到手机上

ClassOUT 是**调试签名的应用**，不在应用市场里，需要用数据线从电脑装一次：

1. 手机上打开「开发者模式」与「USB 调试」（设置 → 关于手机 → 连点版本号 7 次，
   再到 设置 → 系统和更新 → 开发人员选项 里打开 USB 调试）。
2. 用数据线连电脑，在命令行里执行：

   ```bash
   hdc list targets          # 应该能看到你的设备序列号
   hdc install entry-default-signed.hap
   ```

3. 桌面上出现 **ClassOUT** 图标，打开即可。

> ⚠️ 调试签名只在你开着开发者模式的这台设备上能运行。

## 2. 第一次打开：从零开始建课表

第一次打开只有**一个空学期**（默认叫「我的学期」，起始日＝本周一，16 周），
课表要自己建。四个入口都在课表页顶部的 **「管理课程」**：

![管理课程](docs/manual/05-manager.jpg)

### 第 1 步：确认学期和时间

- **学期**：改名字、开学日期、总周数、每周第一天、要不要显示周末。
  开学日期决定「第几周」怎么算，请填**第 1 周的周一**。
- **上课节次时间**：默认是北大校本部的 12 节作息（第 9、12 节是机动节次，格子更矮）。
  可以直接改每一节的起止时间，也可以点「恢复北大默认 12 节」一键还原。

### 第 2 步：新增课程

点右上角 **「+ 新增课程」**，填这几项就可以了：

| 字段 | 说明 |
|---|---|
| 课程名（全称） | 例如「高等数学」 |
| 简称 | 显示在课表格子里，短一点（例如「高数」） |
| 教师 / 默认地点 | 可留空 |
| 颜色 | 10 个色板里挑一个，课表格子会用它上色 |
| 下课自动生成待办 | 打开后，每上完一节会自动生成一条待办（见第 4 节） |
| 虚拟课程 | 「不定时上课」的课（例如网课），不排固定时间，课时自己在计划页安排 |

往下是 **「上课时段」**：点「+ 添加时段」选星期几 + 起止节次 + 生效周次
（`1-16` 表示每周，`1-16单` 表示单周，`1-8,10-16` 表示跳过第 9 周）。
一门课可以有多个时段（例如周二 1-2 节 + 周四 3-4 节）。

### 第 3 步（可选）：配「生成模板」

同一个页面往下是 **「待办生成模板」**：写一个标题模板 + 截止规则，
下课之后就会自动生成待办。标题里可以用变量：

- `%D` = 上课那天的日期（生成出来形如「10.13作业」）
- 右上角的按钮可以插入 `%c`（课程简称）等变量，下面有**实时预览**，看到什么就生成什么。

### 第 4 步（可选）：设不可排时段

到 **设置页 → 不可排时段** 里加「午休」「睡觉」这类时间。
计划页会用淡淡的斜纹把它们标出来，安排待办时会自动避开。

## 3. 课表页

![课表页](docs/manual/01-timetable.jpg)

- 顶部是学期与周次：`‹ 第 N 周 ›` 换周，「今天」跳回本周。
- `＋补课`：临时加一节课；点某个课程格子可以**只改这一周**（换教室 / 挪到别的天 / 本周停课）。
- `管理课程`：就是上面第 2 节那一套。
- 课表格子上的信息：简称 + 地点 + 教师；习题课是**白色虚线框**。
- 底部四个标签：**课表 / 待办 / 计划 / 设置**。

## 4. 待办页

![待办页](docs/manual/02-todo.jpg)

分成三块：

- **待确认**：按「生成模板」自动生成、还没确认的（下课之后生成，确认了才进入待办）。
- **即将考试**：考试类待办会显示倒计时。
- **待办**：正在做的事，左边圆圈点一下就是完成。

底部两个按钮：**「+ 新建待办」**（手动加一条）和 **「+ 考试」**。

![新建待办](docs/manual/06-new-todo.jpg)

新建时可以选**类型**（作业 / 自学 / 考试 / 无，以及你自己加的类型）、截止时间、
**预计耗时**（15–600 分钟，按 5 分钟对齐）、所属课程，还能写一行**备注**。
选「考试」还会多出考试时间与考场。

> **自定义类型**：类型那一排最后是 **「＋ 新建类型」**，点开就能加一个（**全局生效**，
> 之后所有待办都能选它）。不想要的类型去「设置 → 待办类型」里删；删掉时，用了它的
> 待办会改成「无」。

## 5. 计划页

一天一张时间轴。**把「待安排」里的待办拖到网格上就排好了。**

![计划页](docs/manual/03-plan.jpg)

- **日 / 三日**：右上角切换。三日视图一次看三天，可以把待办**横向拖到另一天**。
- **拖拽**：长按待办卡拖动 → 松手落点会吸附到 15 分钟刻度；拖到屏幕上下边缘会自动滚动时间轴。
- **找空档**：待办卡上的「⚡ 找空档」会自动挑一个不与课程冲突的空位放进去。
- **选中与编辑**：点一下块 = 选中，再点一下 = 从右侧滑出**属性面板**（改日期 / 开始时间 / 时长 /
  截止时间，或者标记完成、移除这一块、删除整个待办）。
- **双指缩放**：在选中的块上双指张合可以改时长（5 分钟一档）。
- **待安排**：默认收起成底部一条小胶囊（显示还有几条待办），点它展开、点「收起 ▾」收回；
  排过一次之后它就不再留在托盘里（要挪到别的天，直接拖那一块）。
- **不可排时段**：设置里配的「午休 / 睡觉」会用**淡斜纹**标出来（单日与三日都有）。
- **时间范围（上下限）**：网格从几点画到几点可以在「设置 → 计划页时间范围」里按**半小时**调
  （默认 07:00–24:00），范围之外的课程/计划块会被裁掉。

## 6. 设置页

![设置页](docs/manual/04-settings.jpg)

| 卡片 | 能做什么 |
|---|---|
| **背景** | 从相册选一张照片当背景（会拷进 App 内部保存，**不联网、也不需要相册权限**）；也可以一键恢复默认渐变 |
| **首页标语** | 改启动页 `ClassOUT` 下面那一行字，上限按**显示宽度**算：16 个汉字或 32 个英文字母；留空恢复默认 |
| **动画** | **一键关掉全部动效**（抽屉、托盘、列表增删、打字机、背景光晕漂移都会退化成直接切换，更省电） |
| **提醒** | 每日简报时间、上课提前多少分钟提醒 |
| **不可排时段** | 加「午休 / 睡觉」这类时间（时间用**系统时间滚轮**选），计划页会避开并在网格上淡淡标出 |
| **待办类型** | 加 / 删**自定义待办类型**（内置的作业/自学/考试/无不能删）；删一个类型时，用了它的待办会改成「无」 |
| **计划页时间范围** | 计划网格的**上下限**，按半小时步进（默认 07:00–24:00）；和「不可排时段」是两件事 |
| **新手引导** | 进「演练」：开一个**沙箱**（演示课 + 演示待办），底部一条「第 n/7 步」引导条带你走一遍课表→待办→计划→设置；退出时沙箱整份丢弃 |

## 7. 数据、隐私与备份

- **完全离线**：没有任何联网代码，没有账号，没有统计上报。
- **数据在哪**：全部在这个 App 的私有沙盒里（SQLite 数据库 + 你选的背景图副本），
  卸载 App 就会一起删掉。
- **备份**：`管理课程 → 备份与恢复 → 导出备份` 会生成一个 JSON 文件，
  可以用数据线拷到电脑保存；换机或重装后用「恢复」导入。
  **换手机之前请务必导出一次。**
- **提醒为什么在系统日历里**：鸿蒙对普通应用的「代理提醒」配额是 0 条，
  所以 ClassOUT 把上课与作业截止的提醒**写进系统日历**，由日历负责到点响铃。
  你可以在日历里看到形如「12:45 高等数学 还有 15 分钟上课 · ClassOUT」的事件。

## 8. 常见问题

**Q：待办没有自动生成？**
A：三门检查 —— ① 课程里「下课自动生成待办」是否打开；② 该课程有没有配「生成模板」；
③ 生成的待办会先出现在**待办页的「待确认」**里，确认之后才进「待办」。

**Q：上课提醒没响？**
A：提醒写在**系统日历**里，请确认日历的通知权限是开着的；
另外本 App 是调试签名，只在开着开发者模式的设备上运行。

**Q：怎么把一条待办拆成两天做？**
A：在待办卡上点「⚡ 找空档」排到某一天；再把**三天视图切出来**，把同一张卡拖到另一天
（或者点网格空白处放下）。同一天不会重复排同一块，跨天可以。

**Q：排错了 / 排重了怎么办？**
A：计划页点开那一块 → 「移除此块」；重复的块删掉之后，待办的「预计 N 分钟」
会自动跟着回落（它等于该待办所有块时长之和）。

**Q：题图里的课表怎么和我不一样？**
A：说明书截图来自开发者的手机，只是**示例数据**；你的课表要自己建（见第 2 节）。
